## 1. 개발 의도

이 앱을 왜 만들게 되었나요? 어떤 불편함이나 필요를 발견했나요?

-쓰레기통, 공중화장실, 자전거, 돌아다니다 보면 필요할 때가 많지만, 위치를 찾기는 어려울 때가 있습니다. 그래서 간편하게 내 위치 주변 공공시설들을 찾을 수 있게 이 앱을 만들게 되었습니다.

## 2. 적용 대상

누가, 언제, 어디서 사용하나요?

- 사용 대상: 우리학교 학생, 선생님 전원
- 사용 상황: 간식을 먹고 쓰레기가 생겼을 때, 걷다가 화장실이 급할 때, 공공자전거를 빨리 빌려서 가야 할 때 등 다양합니다.

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 나의 정확한 위치를 찾아줍니다.| GPS 기능을 사용합니다.|
| 내 주변 공공시설의 위치를 지도 위에 아이콘으로 표시합니다. | 공공데이터와 카카오맵을 이용했습니다.|
| 그 공공시설에 대한 다양한 정보도 함께 제공합니다.| 이것도 공공데이터에 올라온 정보를 참조합니다.|

**사용 방법**

1. 앱 주소에 접속합니다.
2. 원하는 시설의 버튼을 클릭합니다.
3. 자동으로 내 주변 시설이 표시됩니다.
4. 시설 정보와 위치, 거리 등을 비교해서 지도를 보며 찾아갑니다.
